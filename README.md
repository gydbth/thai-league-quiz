# ทายนักเตะไทยลีก (Thai League Quiz)

เกมทายนักเตะไทยลีก รอบละ 5 นักเตะ 25 คำถาม จับเวลา 8 วินาทีต่อข้อ (โหมดท้าทาย 5 วินาที) พร้อมการ์ดแชร์ผลมี QR

- เว็บไฟล์เดียว `index.html` ไม่ต้อง build — Vercel ตั้งค่า Framework Preset เป็น **Other** ได้เลย
- ข้อมูลนักเตะอ้างอิง Wikipedia และ Soccerway (ต.ค. 2026) · รูปนักเตะจาก Wikimedia Commons ตามสัญญาอนุญาต CC (เครดิตแสดงในหน้าสรุปผล)
- เกมโดยแฟนบอล ไม่เกี่ยวข้องกับไทยลีกหรือสโมสรใด
